# 架构设计

本目录记录 `essor-router` 与 `essor-start` 的目标架构和实施约束。它不是当前版本 API 的承诺；其中的接口在实施前应经过 RFC、原型和兼容性测试。

- [Router 演进设计](./router-evolution)：将现有浏览器路由器升级为可被同构元框架复用的内核。
- [Essor Start 同构元框架设计](./essor-start)：基于该内核设计的 Essor 专属 Start 框架，已整合 SolidStart、Nuxt、Next.js、Nitro 与 Unhead 的调研结论。
